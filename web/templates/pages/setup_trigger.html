1 · Make a token

This one is going to live in someone else's database, so give it as little power as possible. On github.com → fine-grained tokens:

  • Repository access → Only select repositories → {{ repo or 'this repo' }}
  • Permissions → Repository → {{ token_scope }}
  • Expiration → 90 days, and put a reminder in your calendar

Nothing else. With only this, the worst anyone who steals it can do is start your posting workflow. A classic token with repo scope would hand over your whole account — do not use one.

2 · Make the job

Any service that can send a POST works. cron-job.org is free, needs only an email, and goes down to the minute. Create a cronjob and paste in the four boxes below.

Set its timezone to {{ cfg.timezone }} — the same one your schedule uses. Then daylight saving is handled for you, which is why these times are your local ones and the cron inside post.yml is not.
